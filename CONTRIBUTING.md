# Contributing

Thanks for wanting to help! This is the **open companion resources repo** for
[Detach](https://getdetach.app/?utm_source=github&utm_medium=readme&utm_campaign=shell_repo),
the free iOS 17+ app blocker. It holds MIT-licensed **NFC tag configs**, **Apple
Shortcuts recipes**, and honest docs about reducing screen time.

> **Scope:** the Detach **app itself is closed-source** and is **not** in this
> repo. Please don't open PRs expecting to change the app — file app feedback in
> the app or on [getdetach.app](https://getdetach.app/?utm_source=github&utm_medium=readme&utm_campaign=shell_repo).
> This repo is for the open resources only.

## What we love PRs for

- **New Apple Shortcuts recipes** — focus routines, scheduled blocks, wind-down
  automations. Add a short, honest Markdown write-up in `shortcuts/`.
- **NFC tag configs & guides** — sample NDEF payloads, tag-writing walkthroughs,
  BYO-tag tips in `nfc/`.
- **Docs & honest comparisons** — screen-time guides or alternative round-ups in
  `docs/`. Keep comparisons fair to other products (Brick, Blok, Bloom, Foqos…).
- **Fixes** — typos, broken links, outdated prices/specs.

## Ground rules (please read)

1. **Be honest.** No invented features, no fake benchmarks, no trash-talking
   competitors. If you cite a price or spec, link a source.
2. **Don't fabricate deep links.** Use the universal link
   `https://getdetach.app` in examples. If an app-specific link is needed, mark
   it clearly as `(placeholder — confirm Detach's link)`.
3. **iOS honesty.** Be clear that Apple's Family Controls / Screen Time layer
   does the blocking — a Shortcut or NFC tag only *triggers* it.
4. **Keep it readable.** Real headings, no keyword stuffing.
5. **License.** By contributing you agree your work is released under the repo's
   [MIT License](./LICENSE).

## How to submit

1. Fork the repo and create a branch.
2. Add your file(s) with a clear name (e.g. `shortcuts/pomodoro-block.md`).
3. Open a pull request describing what it does and how you tested it on-device.

Small, focused PRs get merged fastest. Thank you! 🙏
